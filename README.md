# Aula — OAuth com Firebase e Supabase

Repositório de teste para uma atividade prática de autenticação com **Google OAuth**, utilizando **Firebase Authentication** e **Supabase Auth**.

O objetivo é demonstrar duas formas de implementar a autenticação com uma conta Google em uma aplicação web.

## Funcionamento

A página inicial permite escolher entre dois serviços:

- **Firebase:** autenticação com Google por meio de uma janela pop-up.
- **Supabase:** autenticação com Google por meio de redirecionamento.

Após o login, ambos direcionam o usuário para uma página interna compartilhada, que apresenta suas informações básicas e permite encerrar a sessão.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES Modules)
- Firebase Authentication
- Supabase Auth
- Google OAuth 2.0
- GitHub Pages
